Install

  1. Show your browser’s bookmarks bar. In Chrome or Edge, press Ctrl+Shift+B.
  2. Drag the red BuildUVS → TTS button onto the bookmarks bar.
  3. If dragging is unavailable, use Copy bookmarklet, create a bookmark manually, and paste it into the bookmark’s URL field.

Use

  1. Open a deck at builduvs.com/lists/event/rank.
  2. Click the installed bookmark.
  3. Paste the copied deck list into the UVS TTS importer and click Import.

The export includes the starting character, mainboard, sideboard, quantities, and exact set/card-number qualifiers. It reads BuildUVS’s public event deck data rather than scraping the visible card layout.

This bookmarklet only reads the selected deck and copies formatted text. The loaded TTS mod still needs a compatible importer and CardDB.
